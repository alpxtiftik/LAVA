AI Provider

The selected CLI agent explores the raw EMBA logs on its own and writes the verdicts. One-time setup: run claude or agy once in a terminal to log in. No API key needed (uses your existing subscription). Batching is configured in the MCP Agent panel.
Get your free key from Google AI Studio.

MCP Agent

Only applies when the AI provider is MCP Agent (Claude Code / Antigravity).
In MCP Agent mode the findings are sent to the agent in batches of this size (one agent run per batch), which prevents the single-turn timeout on large firmware. 0 disables batching (one giant turn).

EMBA Scan

Only affects Full Pipeline (scan a firmware image). In Analyze EMBA Logs mode EMBA has already run.
  • Auto – run_emba_lava.sh applies a LAVA profile matched to the modules you ticked, so EMBA only runs what that module needs (lava.00-quick-scan for credentials, lava.01-cve-scan for CVE, lava.02-full-lava-scan for both). Much faster.
  • Full – no profile: EMBA runs its complete default module set regardless of what you ticked. Use this if the Auto profile seems to be missing data. LAVA still only analyses the ticked modules.

Custom Grep

When enabled, LAVA runs its own regex rules over the extracted firmware before the AI step and shows those hits in a separate Grep view next to the EMBA results. When disabled, LAVA behaves exactly as before.
Profiles are JSON files in config/scan_profiles/. Put your own in config/scan_profiles/local/.

S99 Coverage

EMBA's grepit is a source-audit tool: most of its "cryptocred" categories match the word password/secret anywhere and can't tell a hardcoded value from ordinary code. LAVA leaves that call to the AI, so the levels only differ in how much obvious noise is pre-removed:
  • raw – every match. The only thing removed is a line that is unreadable binary garbage or not a real file path. Highest recall, most noise. On a full router firmware this can be 2000–3000 S99 findings (MCP Agent mode: dozens of batches, slow).
  • light – raw, minus two things that structurally can't be a config credential: matches inside a compiled binary's string table (*.so, ELF), and static web assets (minified JS libraries, images, .html, locale bundles). Recommended for MCP Agent mode.
  • off – no S99 at all (S45/S106/S107/S108 + Custom Grep still run).
Duplicate hits (same file grepped by two extractors) are collapsed at every level.
