AI Provider

The selected CLI agent explores the raw EMBA logs on its own and writes the verdicts. One-time setup: run claude or agy once in a terminal to log in. No API key needed (uses your existing subscription).
Get your free key from Google AI Studio.

Custom Grep

When enabled, LAVA runs its own regex rules over the extracted firmware before the AI step and shows those hits in a separate Grep view next to the EMBA results. When disabled, LAVA behaves exactly as before.
Profiles are JSON files in config/scan_profiles/. Put your own in config/scan_profiles/local/.

Advanced

narrow keeps only lines where EMBA's regex bank matched an actual assignment (password=, secret:, PEM private keys). broad adds the bare word-matches (Authentication, pass.?wo?r?d, encrypt…key, BEGIN CERTIFICATE) – hundreds of extra hits on real firmware, almost all noise. Use broad only with Local AI / Gemini, never with MCP Agent mode.
In MCP Agent mode the findings are sent to the agent in batches of this size (one agent run per batch), which prevents the single-turn timeout on large firmware. 0 disables batching (one giant turn).
